# Code of Conduct

Budden adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct. The full text is available at the link above.

## Summary

We want Budden to be a welcoming, harassment-free space for everyone, regardless of
experience level, identity, or background. Be kind, assume good faith, and disagree
on the substance, not the person.

## Reporting

If you experience or witness behavior that violates the Contributor Covenant, please
report it privately to:

- Email: `liltorp03@gmail.com` with subject `[budden conduct]`

Reports are read by the project maintainer and kept confidential. Expect an
acknowledgement within 72 hours.

## Enforcement

The maintainer may warn, temporarily restrict, or permanently ban any contributor whose
behavior violates this code. The Contributor Covenant's enforcement guidelines apply.
